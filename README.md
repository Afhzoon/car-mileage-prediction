# car-mileage-prediction
Built a multiple linear regression model in Python to predict car MPG from horsepower, top speed, volume and weight (81 cars). Tested regression assumptions, found strong multicollinearity (VOL-WT 0.99, HP-SP 0.97), analyzed residuals, and saved the model with Pickle. Tools: Python, Pandas, Seaborn, Matplotlib, Scikit-learn
